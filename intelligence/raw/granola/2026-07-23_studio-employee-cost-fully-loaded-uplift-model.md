# Studio Fully-Loaded Employee Cost Model: Early-Stage vs Established Benchmark

## Key Content

Fully loaded employee cost uplift benchmarks for a UK-based game studio, as applied to salary modelling for headcount planning:

**Early-stage studio (pre-benefits buildout):**
- Uplift above base salary: ~20-26%
- Components: employer pension contribution (3% gross via Nest) + employer NI only
- No additional benefit overhead yet (no healthcare, no enhanced leave, no equity)
- Contractor cost: base rate only, no uplift

**Established studio benchmark (Jagex, ~similar function):**
- Uplift: ~31%
- Components: pension + NI + additional benefits overhead

**Salary range modelling structure:**
- Global benchmarks broken down by region: EU/Greece, UK, US
- Hub vs non-hub salary delta within UK: ~30% (e.g. London vs secondary UK city)
- Contractor rates: communicated in day rates, not annual figures (avoids confusion with FTE framing)
- Day rate calculation: annual / 12 (monthly) / 18 (agreed average working days per month)

**Pension note:** early-stage studios often set pension at statutory minimum. Letter to employees should match the Nest configuration (3% on gross salary). Misalignment between what employees were told and what is configured creates retroactive correction risk.

## Decisions / Insights

- Glen and finance lead agreed: 20-26% fully loaded uplift is the working assumption for early-stage studio headcount cost modelling
- Glen observed: communicating contractor rates as annual figures causes confusion -- day rate framing is clearer for contractors and HR
- Pattern identified: studios frequently set pension at statutory minimum but fail to configure the system to match what was communicated to employees -- check configuration vs employee letters before any review period
- Data point: Jagex fully loaded uplift runs at ~31%, ~5-11 points above an early-stage studio with pension+NI only
