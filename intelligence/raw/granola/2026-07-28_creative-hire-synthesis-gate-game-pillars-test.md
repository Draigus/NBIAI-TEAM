# Creative Hire Synthesis Gate: Game Pillars as an Onboarding Test

## Key Content

A new senior creative hire (Game Director level) at a ~55-70 person studio was assigned game pillars as their first deliverable -- a 7-slide presentation-format document synthesising the game's creative direction. This is an intentional diagnostic test, not just a task.

**Red flag observed:** The new hire asked the CPO for their existing draft to build from rather than synthesising independently. CPO declined -- this is the correct response because independent synthesis is the capability being tested. A senior creative who cannot synthesise direction from sources without a scaffold is not demonstrating GD-level capability.

**Format calibration:** The assignment was explicitly scoped as "7 presentation-style slides" not a "23-page document." The distinction matters: a presentation format requires distillation and prioritisation; a long-form document allows hiding behind completeness. The shorter format tests executive-level communication as much as creative thinking.

**Roles and responsibilities clarity:** When a new senior creative hire joins, a written framework defining the boundaries between adjacent roles (EP, CD, GD, Design Director) reduces gray-area disputes and prevents authority ambiguity. The CPO drafted this framework externally and shared it with a trusted existing lead for collaborative refinement -- notably not with the new hire yet, because trust had not been established.

**Trust threshold for co-authorship:** The CPO distinguished between someone you trust enough to co-author a working document (requires demonstrated reliability) and someone you assign a deliverable to (requires only competence). A new hire starts in the latter category.

## Decisions / Insights

- Studio CPO decided: when a new creative hire asks for existing drafts to build from, decline -- independent synthesis is the capability being tested
- Studio CPO established: game pillars as first deliverable is a format-and-synthesis test; 7 slides not a 23-page document is an explicit scope calibration that reveals executive communication capability
- Studio CPO decided: co-authoring the roles/responsibilities framework with the new hire is premature; trust must be established first through demonstrated reliability on assigned deliverables
- Studio CPO observed: the correct pattern is to develop role boundary documents with trusted existing leads and share with new hires as direction, not to co-author them with unproven hires

## Context

Onboarding review of a new Game Director hire at a ~55-70 person MMO studio, July 2026. The hire had been in the role for some weeks. Game pillars was the first assigned deliverable. CPO noticed the request for an existing draft and recognised it as a diagnostic signal about synthesis capability. A roles-and-responsibilities framework was drafted in parallel to address authority ambiguity between the GD, EP, CD, and Design Director roles.
