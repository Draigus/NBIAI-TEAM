# Sprint Cadence for AAA Indie: Tech Debt Budgeting, Alternating Doc Reviews, VS1 Roadmap Format

## Key Content

Production rhythm and governance model established for a ~65-person MMO studio entering vertical slice production.

**Tech debt management:**
- Tech debt logged as Jira tickets, prioritised alongside features each sprint
- Target burn rate: 10-30% of sprint capacity allocated to tech debt
- Exact ratio to be set by incoming CTO; 10-30% is the committed floor-to-ceiling range
- Tech debt treated as first-class work, not a separate stream

**GDD and TDD review cadence:**
- GDD and TDD reviews alternate every other sprint (not every sprint)
- Duration: approximately one hour per session
- Sampling approach: review for staleness, not exhaustive re-reads
- Producers review art style guides and design docs at each definition-of-done stage

**Definition of done process:**
- DoDs nearly complete across all departments at the time of this meeting
- Character art was the only outstanding DoD; chased and closed same day
- DoDs must be locked before the leads call

**VS1 roadmap deliverable:**
- Primary stake-in-the-ground deliverable: a PowerPoint showing features, priority order, and timeline for VS1
- Scope decision process: senior advisor reviews sheet and separates core path vs. non-core path features; non-core goes to a review list; then a 3-4 hour session with game director and creative director to finalise VS1 scope
- EP attends the scoping session as guidance, not as a decision-making voice

## Decisions / Insights

- Glen and EP decided: tech debt is managed as Jira tickets in the same priority queue as features; 10-30% sprint capacity is the agreed burn rate range pending CTO confirmation.
- Glen and EP decided: GDD/TDD reviews alternate every other sprint at approximately one hour each; producers check art guides and design docs at every DoD stage.
- Glen decided: VS1 scope is locked via a 3-4 hour session with the game director and creative director after the senior advisor has pre-separated core vs. non-core path features.
- Glen decided: the primary VS1 deliverable format is a PowerPoint roadmap (features, priority, timeline) -- the first concrete stake in the ground for the studio.

## Context

Production meeting at a ~65-person MMO studio in vertical slice production, Jul 1 2026. Attended by senior advisor (Glen), EP (Valeria), and producer (Fred, onboarding). The meeting addressed estimation finalisation, scope lock process, and production governance for the vertical slice phase.

- Relevant when: establishing production cadence for a studio transitioning from pre-production to vertical slice -- the alternating GDD/TDD review schedule and tech debt budget are directly applicable.
