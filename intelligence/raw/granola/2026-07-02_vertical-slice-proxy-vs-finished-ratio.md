# Vertical Slice Scope: Proxy State vs Fully Finished Ratio (~1:1.8)

## Key Content

Scope estimation model for art vertical slices, using two distinct quality tiers to separate pitch-readiness from production-readiness.

**Two-tier model:**
- Tier 1 -- Proxy state with base colour: minimum viable fidelity to convey spatial layout, scale, and rough aesthetic. This is the primary vertical slice target.
- Tier 2 -- Fully finished set dressing: complete texture, props, lighting, and detail pass for production handoff.

**Estimated ratio:** If proxy = 100 hours, fully finished = approximately 180--220 hours (~1:1.8 to 1:2.2).

**Pitch-specific skunkworks approach:** Alongside the main vertical slice, commission one "icon building" as a parallel skunkworks track. Goal: show pitch audience a single example of near-complete fidelity without blocking the primary tier-1 pipeline. Criteria for selection: a simple building that can be dressed quickly. Fallback: AI-enhanced render of the proxy kit if a full in-engine build is not feasible within the window.

**Prioritisation rule:** Tier 1 across the full slice first. Vertical slices 2, 3, and 4 do not exist until VS1 is complete. The skunkworks "icon" is the only exception to the single-focus rule, and only because it serves a separate pitch audience function.

## Decisions / Insights

- Glen decided: vertical slice target is tier 1 (proxy state) only; the ratio makes tier 2 a separate, later-phase commitment, not a shared goal with the current sprint.
- Glen decided: one icon building as a skunkworks parallel track for pitch purposes, selected for simplicity of dressing, kept off the main team pipeline.
- Glen observed: the proxy-to-finished ratio is roughly 1:1.8, meaning a studio that scopes only against finished art will approximately double the time actually needed for a pitch-quality deliverable.

## Context

Solo working notes by NBI senior advisor at a ~55-person MMO studio, 2 July 2026. Scope discussion was in the context of an upcoming investor pitch requiring a vertical slice. The two-tier model was agreed with the lead environment artist (Graham) and the art director.

## Applicability

- Relevant when: scoping a vertical slice for investor pitch -- the proxy/finished split allows the team to produce a pitch-ready deliverable at roughly half the cost of a production-finished one.
- Relevant when: a studio is treating "vertical slice" and "production-ready" as synonymous -- the ratio makes the cost difference concrete and justifies the two-tier approach.
- Relevant when: pitch preparation requires one standout environment or building -- the skunkworks "icon" model isolates that effort from the main VS pipeline and prevents it from blocking tier-1 delivery.
- Relevant when: a client is uncertain whether AI rendering tools can substitute for in-engine fidelity at pitch stage -- the fallback (AI-enhanced render of proxy kit) is a viable contingency if production speed is the constraint.
