## Bug Fix: Hiring pipeline wrong stage confirmations for client users

### Bugs
- `281e2c2e` - "Changing someone to rejected" shows onboarded confirmation

### Root Cause
For client users (e.g. Ryan Templeman at Couch Heroes), `_hiringFilterClient` was never set to their client ID. Line 578 in `nbi-hiring.js` only handled the non-client case (`if (!isClientUser()) window._hiringFilterClient = null`), leaving it undefined for client users.

This caused:
1. Kanban lanes showed the 6 default pipeline stages instead of Couch Heroes' custom 7-stage pipeline
2. Mobile "Move to" select in cards showed default stages
3. Custom stages (Signed, Declined/Rejected) were invisible in the Kanban
4. Stage transition confirmations referenced the correct pipeline but mismatched what the user saw

### Fix Applied
- `public/js/domains/nbi-hiring.js:578` - Added `isClientUser()` branch to set `_hiringFilterClient = _currentUser.clientId`
- Database: Fixed "declined-rejected" label to "Declined / Rejected" for Couch Heroes pipeline
