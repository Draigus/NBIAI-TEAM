### Entry 4 — Calendar-events 500 root-caused (fixing this session)

`GET /api/calendar-events` returns 500 for Stavros — `column reference "client_id" is ambiguous`.

**Root cause:** `buildCalendarVisibilityClause` in `routes/calendar.js` emits unqualified column names (`user_id`, `visibility`, `client_id`, `team_id`). Both queries that use it join `users u`, and migration 026 added `client_id` to `users`, so `client_id = ANY(...)` is ambiguous between `ce.client_id` and `u.client_id`. The branch only activates for NON-admin users with at least one assigned client task (admins short-circuit to `TRUE`) — which is why it hits Stavros but never Glen.

**Fix:** qualify all columns in the clause with `ce.` (both call sites use the `ce` alias). Regression test written first: `tests/unit/calendar-visibility-ambiguous.test.mjs` (3 tests). Waiting for background unit suite to finish before running (single-writer test convention), then: run test unfixed (expect 500 repro) → apply fix → re-run (expect green).
